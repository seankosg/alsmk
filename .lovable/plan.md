

## ALSMK Construction Project Management App — Full Build Plan

This is a large build. We'll create everything in phases within a single implementation pass: Supabase schema, dark mode theming, app layout with sidebar navigation, and all major pages with mock data (to be connected to Supabase).

---

### Phase 1: Foundation & Dark Mode

**Force dark mode** — Add `dark` class to `<html>` in `index.html`. Update CSS variables for a professional dark construction-management aesthetic.

**Install `xlsx` package** for Excel import/export functionality.

**Create memory file** with design decisions and project specs.

---

### Phase 2: Supabase Schema (Migrations)

Create all tables via Supabase migrations:

```text
teams (id, name, code, created_at)
parts (id, team_id FK, name, code, created_at)
members (id, user_id FK nullable, team_id FK, part_id FK, name, duty_title, created_at)
user_roles (id, user_id FK, role enum(admin/manager/user))
milestones (id, name, target_date, sort_order, status enum, created_at)
tasks (id, task_code unique, title, milestone_id FK, team_id FK, part_id FK, assignee_id FK, start_date, end_date, current_progress int, issue_flag enum, issue_type, issue_description, created_by, created_at, updated_at)
task_code_sequences (team_code, part_code, yymm, seq) — for atomic code gen
issue_threads (id, task_id FK, author_name, message, created_at)
activity_log (id, user_name, action, entity_type, entity_id, details jsonb, created_at)
personnel_targets (id, team_id FK, part_id FK, target_headcount, current_headcount)
```

**Task Code Trigger:** PL/pgSQL `BEFORE INSERT` on `tasks` — looks up team/part codes, atomically increments sequence, sets `task_code = '{TeamCode}-{PartCode}-{YYMM}-{0001}'`.

**Indexes:** tasks(team_id, issue_flag, assignee_id, milestone_id), activity_log(created_at DESC).

**RLS:** Enable on all tables. Use `has_role()` security definer function. Dev mode bypasses auth.

**Seed data:** 4 teams (DES, PRO, BUD, CON) with sample parts, milestones, members, and tasks.

### Phase 3: App Layout & Routing

**Sidebar layout** using shadcn `Sidebar` component:
- Logo/title: "ALSMK"
- Nav items: Dashboard, My Workspace, Directory, Admin, Import
- Collapsible with icon-only mode

**Routes:**
- `/` — Master Dashboard
- `/login` — Login page (bypassed in dev mode)
- `/workspace` — My Workspace
- `/directory` — Member directory (read-only)
- `/admin` — Admin Panel (tabs: Teams/Parts, Members, Milestones)
- `/tasks/import` — CSV/Excel import

**Global header:** Project name + notification bell icon.

---

### Phase 4: Master Dashboard ("The Cockpit")

All components built with mock data initially, then wired to Supabase queries:

1. **MilestoneTimeline** — Horizontal subway-map style with dots, connecting lines, "Today" pin, milestone labels/dates. Scrollable if many milestones.

2. **ProjectHUD** — Row with:
   - Large donut chart (Recharts `PieChart`) showing Overall Planned vs Actual %
   - D-Day counter card (days to final milestone)
   - Summary stats cards (total tasks, active issues, completion rate)

3. **TeamHeatmap** — Grid of Team→Part blocks. Color: green (normal), amber (warning), red (severe issues). Click a block to open a Sheet/Drawer listing delayed tasks with issue details.

4. **CriticalIssueBoard** — Card with sorted list of tasks where `issue_flag != 'normal'`. Shows task code, title, severity badge, assignee, gap %.

5. **ActivityStream** — Scrollable card with paginated activity log entries (lazy-loaded). Each entry: timestamp, user, action description.

6. **PersonnelTable** — shadcn Table: Team, Part, Target HC, Current HC, Vacancy (computed).

---

### Phase 5: Task Management & Workspace

- **Task list table** — Columns: Task Code, Title, Milestone, Assignee, Dates, Planned %, Current %, Gap (blue/red), Issue Flag badge. Filterable by team/part/flag.
- **Planned %** auto-calc: `min(100, max(0, (today - start) / (end - start) * 100))`
- **Gap** = Current % - Planned %, displayed blue (≥0) or red (<0)
- **Task detail dialog** — Full info, progress slider, issue flag toggle, issue fields (required when flag ≠ normal), issue thread/comments
- **My Workspace** — Filtered to current user's tasks, auto-save interval selector, "Export to Excel" button
- **Directory** — Browse members, view their tasks read-only

---

### Phase 6: Admin Panel

- **Org tab** — CRUD Teams (name + code) and Parts (name + code + parent team)
- **Members tab** — Add/edit members with team, part, duty_title assignment
- **Milestones tab** — Add/edit/reorder milestones with target dates
- **Task reassignment** — Admin can reassign tasks between members

---

### Phase 7: CSV/Excel Import

- **Download Template** button — generates .xlsx with columns: Title, Milestone, Team Code, Part Code, Assignee, Start Date, End Date
- **Upload** — Parse xlsx/csv, show preview table, validate, bulk insert (task codes auto-generated by DB trigger)
